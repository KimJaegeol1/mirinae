# 미리내 iPhone 참여자 현장 설치 설명서

미리내는 송금하거나 출금하는 앱이 아닙니다. 자동연결로 확인하거나 참여자가 직접 입력한 현재 잔액에서 이번 고정비, 과거 미납 고정비와 안전완충액을 빼서 `지금 써도 되는 돈`을 보여줍니다. 고정비는 소득일과 별개로 매월 새 회차가 생깁니다.

```text
현재 계좌 잔액
- 이번에 남겨둘 고정비
- 과거 미납 고정비
- 안전완충액
= 지금 써도 되는 돈
```

## 시작하기 전에

다음 조건을 모두 확인합니다.

- iPhone과 인터넷 연결이 필요합니다.
- App Store에서 Scriptable을 설치할 수 있어야 합니다.
- 이번 자동연결은 팝빌이 지원하는 일반은행 계좌만 가능합니다.
- 카카오뱅크·토스뱅크·지역 농축협처럼 자동연결이 안 되는 계좌는 직접 입력 모드로 사용할 수 있습니다.
- 계좌번호·비밀번호·생년월일은 참여자 본인이 직접 입력합니다. 진행자에게 말하거나 화면을 보여주지 않습니다.
- 설치 중 오류가 나도 계좌정보가 보이는 화면을 캡처해 전송하지 않습니다. 오류 문구와 오류 코드만 알려줍니다.

## 1단계: 내 은행이 가능한지 확인

진행자에게 은행 이름만 말하고 지원 여부를 확인합니다.

팝빌 일반은행 경로에서 선택할 수 있는 은행은 산업은행, 기업은행, 국민은행, 수협은행, NH농협은행, 우리은행, SC제일은행, 한국씨티은행, iM뱅크, 부산은행, 광주은행, 제주은행, 전북은행, 경남은행, 새마을금고, 신협, 우체국, 하나은행, 신한은행입니다.

- NH농협은행과 지역 농·축협은 다를 수 있습니다. 지역 농·축협 계좌라면 현장에서 임의로 진행하지 말고 먼저 연결 가능 여부를 확인합니다.
- 카카오뱅크·토스뱅크·케이뱅크는 이 iPhone 자동연결 경로에서 선택하지 않습니다.

## 2단계: Scriptable 설치

1. App Store를 엽니다.
2. `Scriptable`을 검색합니다.
3. Scriptable 앱을 설치합니다.
4. 설치가 끝나면 Scriptable을 한 번 열었다가 닫습니다.
5. iPhone의 `설정`에서 Scriptable의 `셀룰러 데이터`와 `백그라운드 앱 새로고침`을 허용합니다.

백그라운드 앱 새로고침을 허용해도 위젯의 정확한 실행 시각은 iPhone이 결정합니다. 20분은 요청 주기이며 매번 정확히 20분에 실행된다는 뜻은 아닙니다.

## 3단계: 미리내 파일 받기

진행자가 보여주는 `mirinae-iphone-qr.png` QR코드를 Safari 카메라로 읽습니다.

- 설치 안내: `https://sseuldon-popbill-staging.seongin1653.workers.dev/iphone-install`

1. 진행자가 보여주는 iPhone 설치 링크를 Safari에서 엽니다.
2. `다운로드`를 누릅니다.
3. `파일` 앱을 열고 `다운로드` 폴더로 이동합니다.
4. `Mirinae-iPhone-Test.zip`을 한 번 눌러 압축을 풉니다.
5. 생성된 폴더를 열고 `Mirinae.js`를 길게 누릅니다.
6. `이동`을 누르고 `iCloud Drive` → `Scriptable` 폴더로 이동합니다.
7. Scriptable 폴더가 보이지 않으면 Scriptable을 다시 한 번 연 뒤 파일 앱으로 돌아옵니다.

`Mirinae2.js`가 함께 들어 있어도 첫 계좌는 `Mirinae.js`만 사용합니다. 진행자가 두 번째 계좌 시험을 요청한 경우에만 `Mirinae2.js`를 사용합니다.

## 4단계: 잔액 확인 방식 선택

### A. 팝빌 지원 일반은행 자동연결

주변 사람이 화면을 보지 않도록 한 뒤 참여자 본인이 진행합니다.

1. Scriptable을 엽니다.
2. 목록에서 `Mirinae`를 누릅니다.
3. `일반은행 연결 (팝빌)`을 누릅니다.
4. 자신의 은행을 선택합니다.
5. 진행자가 현장에서 안내한 워크숍 초대코드를 입력합니다.
6. 계좌 별칭을 입력합니다. 예: `생활비 계좌`
7. 계좌번호를 하이픈 없이 입력합니다.
8. 계좌 비밀번호 앞 4자리를 입력합니다.
9. 생년월일 6자리를 `YYMMDD` 형식으로 입력합니다.
10. 은행이 요구할 때만 추가 정보를 입력합니다.
    - 국민은행: 인터넷뱅킹 ID
    - iM뱅크·신한은행·신협: 조회전용 ID와 조회전용 비밀번호
11. 개인정보 처리 안내를 읽고 동의합니다.
12. `연결`을 누르고 첫 잔액 확인이 끝날 때까지 화면을 닫지 않습니다.

같은 오류가 두 번 연속 나오면 계속 다시 누르지 말고 멈춥니다. 진행자에게 계좌정보가 아닌 `오류 문구와 오류 코드`만 보여줍니다.

### B. 자동연결이 안 되는 계좌 직접 입력

1. Scriptable에서 `Mirinae`를 실행하고 `잔액 직접 입력`을 누릅니다.
2. 워크숍 참여자 코드와 은행 앱에 표시된 현재 잔액을 입력합니다.
3. 계좌번호·비밀번호·생년월일은 입력하지 않습니다.
4. 이어서 소득 예상일·안전완충액·고정비를 설정합니다.
5. 위젯 상단에 `직접 입력`과 마지막 입력시각이 표시되는지 확인합니다.

직접 입력 기록은 이 iPhone 안에만 저장되며 미리내 서버나 팝빌로 자동 전송되지 않습니다.

## 5단계: 미리 낼 돈 설정

연결 후 다음 항목을 입력합니다.

1. 소득 방식에서 `매월 비슷한 날` 또는 `날짜가 불규칙하거나 아직 모름`을 선택합니다.
2. 정기소득은 매월 예상일 `1~31`, 불규칙소득은 아는 경우에만 예상일을 입력합니다.
3. 비상시에 남겨둘 `안전완충액`과 고정비 개수를 입력합니다.
4. 각 고정비를 `매월 반복` 또는 `한 번만 납부`로 정하고 이름, 금액과 첫 납부일을 입력합니다.
    - 예: 월세 300,000원, 2026-08-05
    - 예: 통신비 55,000원, 2026-08-12
매월 반복 고정비는 납부일 다음 날부터 다음 달 회차가 자동으로 생깁니다. 이전 회차를 내지 않았다면 이전 미납액과 다음 회차를 모두 차감하고 위젯에 미납 경고를 표시합니다.

## 6단계: 계산이 맞는지 확인

진행자에게 잔액을 말하지 않고 참여자 본인이 다음 계산을 확인합니다.

```text
은행 앱의 현재 잔액
- 미리내에 표시된 남은 고정비
- 안전완충액
= 미리내의 지금 써도 되는 돈
```

- 결과가 같으면 다음 단계로 갑니다.
- 결과가 다르면 위젯을 설치하지 말고 진행자에게 `계산 결과가 다름`이라고만 알립니다.
- 음수라면 0원으로 숨기지 않고 부족액이 표시되는 것이 정상입니다.

## 7단계: 홈 화면 위젯 추가

1. iPhone 홈 화면의 빈 곳을 길게 누릅니다.
2. 왼쪽 위의 `+`를 누릅니다.
3. `Scriptable`을 검색해 선택합니다.
4. 중간 크기 위젯을 골라 `위젯 추가`를 누릅니다.
5. 추가된 위젯을 길게 누르고 `위젯 편집`을 누릅니다.
6. `Script`에서 `Mirinae`를 선택합니다.
7. `When Interacting`은 기본값인 `Run Script`를 사용합니다.
8. 홈 화면으로 돌아와 금액, 미납 경고, 남은 고정비, 다음 고정비·예상 소득일까지 남은 날짜와 마지막 확인 시각을 확인합니다.

## 8단계: 매일 사용하는 방법

- 자동연결 사용자는 위젯이 새 잔액을 요청합니다. iOS 사정에 따라 요청 시각이 늦어질 수 있으며, 즉시 확인하려면 `지금 잔액 새로고침`을 누릅니다.
- 직접 입력 사용자는 결제·이체 직후 `지출 입력`, 돈이 들어오면 `입금 입력`을 누릅니다.
- 입력을 빠뜨렸다면 `은행 잔액과 맞추기`에서 실제 은행 잔액과 정정 메모를 남깁니다.
- `최근 수동 기록 보기`에서 기록을 확인하고, `수동 입력 기록 공유`를 눌렀을 때만 참여자가 선택한 앱과 사람에게 CSV 내용을 보냅니다.
- 고정비를 실제로 냈다면 `고정비 납부·미납 관리`에서 해당 월 회차를 `납부 완료`로 바꿉니다. 최신 잔액이 확인돼야 처리됩니다.
- 납부일을 넘기면 `○월 ○○ 미납`이 표시되고 이전 미납액과 다음 회차가 함께 차감됩니다.
- 고정비나 안전완충액을 바꾸려면 `고정비·소득 예상일 수정`을 사용합니다.
- 핵심 금액 숫자는 검정색으로 유지됩니다. 아래 게이지가 여유에 따라 초록색 → 주황색 → 빨간색으로 바뀌고 짧아집니다.
- 5만원 미만에서는 위험 표시가 강해집니다.
- iPhone 홈 위젯은 지속 애니메이션 대신 게이지 색상·길이와 미납 문구로 위험을 알려줍니다.

## 9단계: 이상할 때

### `잔액 확인 필요`가 표시됨

마지막 정상 잔액을 24시간 넘게 받지 못한 상태입니다. 은행 앱에서 실제 잔액을 확인하고 진행자에게 `24시간 이상 갱신 안 됨`이라고 알립니다. 오래된 금액을 믿고 소비하지 않습니다.

### `앱 세션 토큰이 필요합니다`가 표시됨

이전 연결정보가 없거나 오래된 파일일 수 있습니다. 최신 설치 ZIP의 `Mirinae.js`를 다시 넣고 계좌 연결을 다시 진행합니다.

### 연결에 실패함

계좌번호·비밀번호·생년월일을 진행자에게 보내지 않습니다. 오류 문구와 팝빌 오류 코드만 전달합니다. 같은 입력을 반복하지 않습니다.

### 금액이 은행 앱과 다름

즉시 소비 판단에 사용하지 말고 진행자에게 알립니다. 고정비 납부 상태, 안전완충액, 마지막 갱신시각을 먼저 확인합니다.

## 10단계: 파일럿 종료

1. Scriptable에서 `Mirinae`를 엽니다.
2. 자동연결 사용자는 `계좌 연결 해제`, 직접 입력 사용자는 `직접 입력 설정 삭제`를 누릅니다.
3. 연결 해제 완료 문구를 확인합니다.
4. 홈 화면에서 미리내 Scriptable 위젯을 제거합니다.
5. 파일 앱의 `iCloud Drive/Scriptable`에서 `Mirinae.js`를 삭제합니다.
6. Scriptable을 더 사용하지 않는다면 앱도 삭제합니다.

연결 해제가 실패하면 앱과 파일부터 지우지 말고 오류 코드만 진행자에게 알립니다. 서버와 팝빌 연결이 먼저 해제됐는지 확인한 뒤 삭제합니다.
