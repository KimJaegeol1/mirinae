# 미리내 iPhone 워크숍 설치본

`Mirinae.js`는 미리내 연구 파일럿 전용 Scriptable 위젯입니다. 소스 파일의 내부 이름은 기존 설치 호환을 위해 `SseuldonPilot.js`로 유지하지만, 참가자 설치본에는 `Mirinae.js`로 들어갑니다. 기존 CODEF용 `personal-sync/Sseuldon.js`와 섞어 쓰지 않습니다.

## 운영진 사전 준비

1. HTTPS로 배포한 새 `backend` 주소를 준비합니다.
2. 서버 환경변수에 팝빌 운영키, 참여코드, 암호화키, 영구 데이터 파일 경로를 설정합니다.
3. `GET /health`의 `pilotReady`가 `true`인지 확인합니다.
4. Windows에서 아래 명령으로 서버 주소가 내장된 참가자용 ZIP을 만듭니다.

```text
powershell -ExecutionPolicy Bypass -File .\build-release.ps1 `
  -ApiBaseUrl https://api.example.com
```

5. 닫힌 파일럿 참가자에게 `dist/Mirinae-iPhone.zip`만 전달합니다. 원본 파일은 서버 주소 입력을 요구하므로 배포하지 않습니다.

팝빌 운영 전환 전 본인 기기에서만 점검할 때는 `-Channel test`를 붙입니다. 이 경우
`dist/Mirinae-iPhone-Test.zip`이 생성됩니다. 현재 팝빌 테스트환경의 유료 계좌 자리를 사용하는 닫힌 10명 현장 파일럿에서만 진행자가 직접 설치를 도울 때 전달합니다. 링크를 일반 공개하지 않습니다.
테스트 ZIP에는 기존 연결을 유지한 채 다른 계좌를 확인할 수 있는
`Mirinae2.js`도 함께 포함됩니다.

## 참여자 iPhone 설치

1. App Store에서 Scriptable을 설치합니다.
2. `Mirinae.js`를 `iCloud Drive/Scriptable`에 넣습니다.
3. Scriptable에서 `Mirinae`를 실행합니다.
4. 일반은행은 `일반은행 연결 (팝빌)`을 누릅니다. 카카오뱅크·토스뱅크·지역 농축협처럼 자동연결이 안 되는 계좌는 `잔액 직접 입력`을 누릅니다.
5. 다음 소득일, 안전완충액, 고정비를 입력합니다.
6. iPhone 홈 화면을 길게 누르고 `+` → `Scriptable` → 중간 크기 위젯을 추가합니다.
7. 위젯을 길게 눌러 `위젯 편집` → Script → `Mirinae`를 선택합니다.

직접 입력 모드는 초기 잔액을 저장한 뒤 결제할 때 `지출 입력`, 돈이 들어올 때 `입금 입력`을 누릅니다. 기록은 iPhone 안에만 남고 `수동 입력 기록 공유`를 눌렀을 때만 사용자가 선택한 앱과 사람에게 전달됩니다.

참가자용 설치본에는 운영 서버 주소가 내장된다. 주소를 직접 입력하게 하지 않으며, 최초 연결 전 서버의 영구 저장·운영 준비 상태를 검사한다.

## 갱신·경고 동작

- 위젯은 20분 뒤 갱신을 요청합니다. 실제 실행 시각은 iOS가 결정합니다.
- 위젯을 눌러 `지금 잔액 새로고침`을 실행하면 즉시 조회를 요청합니다.
- 조회 실패 시 0원으로 바꾸지 않고 마지막 정상 잔액을 유지합니다.
- 정상 잔액이 24시간 넘게 확인되지 않으면 숫자를 숨기고 `잔액 확인 필요`를 표시합니다.
- 금액 숫자는 진한 검정색을 유지합니다.
- 금액 아래 게이지가 여유에 따라 초록·주황·빨강으로 바뀌고 짧아집니다.

iOS 홈 화면 위젯은 정지된 화면이라 앱 삭제 모드처럼 계속 움직일 수 없습니다. 미리내는 게이지 색상·길이와 미납 문구로 위험을 표시합니다.
