## 2. 시간순 기록

### 9/20 — 킷 만들기, 아이폰에 Scriptable 위젯 띄우기
- 핸드오프 분석: 핵심 로직은 서버(Cloudflare Worker)에 있고 앱은 표시만 함. 구현체 4개 중 iOS 네이티브(SwiftUI)만 옛 금융결제원 백엔드 기준이라 현행과 불일치. `POPBILL_MODE`에 mock 분기가 없어 `wrangler dev`만으로는 잔액을 못 받음.
- 서버 없이 되는 길 = 두 클라이언트에 이미 있는 **수동입력 모드**(서버 호출 0회). 이걸 MVP 경로로 결정.
- 킷 v1 제작: Android 소스(debug 매니페스트·교차검증 테스트 추가) + Scriptable(원본·`build-local.mjs`·고친 `manual-mode.test.mjs`) + `verify/`(12 시나리오). Android 단위테스트 13개 통과 확인.
- zip이 Windows에서 "빈 폴더"로 보인 원인: 한글 파일명에 UTF-8 플래그가 없었음 → 폴더·파일명 전부 영문으로 재패키징.
- 아이폰: "올바른 포맷이 아니라 읽을 수 없음" 오류는 Scriptable 예제(`Read MacStories`)가 실행된 것이었음 → `Mirinae.scriptable`(공식 설치 파일 형식)로 다시 전달 → 메뉴 4개 정상 표시.
- 안드로이드는 팀의 서명된 파일럿 APK(SHA-256 `5CCB2000…` 문서와 일치)를 그대로 설치 파일로 전달.
- "진짜 앱으로" 요청 → Mac이 있다고 해서 **네이티브 iOS 앱을 현재 로직으로 새로 작성**(`ios-native/`): Android 계산기 1:1 이식 + Scriptable 장부 기능 + WidgetKit 위젯 + 테스트 25개. Linux에서 작성해 Xcode 컴파일은 못 했고, 독립 리뷰로 컴파일 오류 후보 수정.

### 9/25 — Mac 개발환경, GitHub, 백엔드 mock, 서버 모드 확인
- **Xcode**: App Store에 안 보인 이유는 인텔 맥 + macOS 26 Tahoe(인텔 마지막 버전)라 최신 Xcode가 숨겨진 것. 개발자 사이트에서 받은 첫 파일은 베타(Apple silicon 전용)라 실행 거부 → **Xcode 26.6 Universal** 설치. 데스크탑에 풀려 있던 걸 `/Applications`로 옮기고 `xcode-select`·약관·구성요소 설치.
- **Homebrew가 인텔 맥 지원 중단** → XcodeGen을 소스에서 직접 빌드(`git clone` → `sudo make install`). `SettingPresets` 복사가 경로 문제로 빠져 수동 복사.
- `xcodegen generate` → `Mirinae.xcodeproj` 생성. 서명에서 "no devices / no provisioning profile" 경고는 실기기용이라 시뮬레이터엔 무관. 기기 선택은 툴바 대신 Product → Destination 메뉴 사용. **iPhone 17 시뮬레이터에서 앱 실행 성공.**
- **GitHub**: `~/dev/mirinae-local-mvp-v0.7.0`를 저장소로 초기화, `.gitignore`(xcodeproj·빌드 산출물·비밀값 제외), SSH 키로 push. 검증: 킷 63개 파일 전부 동일하게 올라감, 비밀값 없음. 저장소가 Public이라 Private 전환 권장.
- **백엔드 mock**: 별도 mock 서버를 새로 짜지 않고 팀 Worker를 그대로 실행. `wrangler.mock.jsonc`의 `alias`로 `popbill` npm 패키지만 가짜 SDK(`src/mock/fake-popbill-sdk.ts`)로 바꿔치기, `/mock/` 제어 페이지 추가(`src/mock/index.mock.ts`). 팀 코드 무수정. 부산물로 `package-lock.json` 생성(인수인계서 PILOT-01 해결), vitest는 npm 버그로 4→3.x.
  - 검증(리눅스에서 실행): health testReady → 연결 201 → 예산 저장 → 위젯 요약 → 가짜 은행 잔액 변경 → 캐시 유지 → 강제 새로고침 반영 → 납부완료(최신 잔액 확인 규칙) → 위젯 토큰 권한 분리 401 → 잘못된 초대코드 403 → 등록 실패 502(끝 0000) → 첫 조회 지연 202 pending(끝 9999) → cron 동기화로 fresh → admin/status → 해제 204 → 이후 401. 팀 테스트 13개 통과.
- Mac에서 `npm install` → `npm run mock:db` → `npm run mock` 실행. 저장소에 `backend/` 커밋·push.
- **터널**: 아이폰 Scriptable은 https만 받으므로 `cloudflared` 임시 터널로 `localhost:8787`을 공개 https 주소로 연결. `/health` 응답 확인.
- **아이폰에서 서버 모드 성공**: Scriptable `일반은행 연결 (팝빌)` → 터널 주소 → 초대코드 `MIRINAE-MOCK-2026`, 계좌번호 `11012341234` → 연결 → 고정비 설정 → 위젯에 서버 계산값 표시. 즉 "Mac 서버 → 터널 → 폰 위젯" 전 구간이 내 컴퓨터로 동작.

## 3. 알아두면 좋은 사실 (하면서 확인된 것)

- 인텔 맥 + Tahoe 조합은 Xcode 26.x Universal이 마지막 세대. App Store에 Xcode가 안 뜨는 게 정상이고, 개발자 사이트의 "Universal" 표기 파일만 된다.
- Homebrew는 인텔 맥에서 더 이상 설치되지 않음. 필요한 도구는 nodejs.org `.pkg`, GitHub 릴리스 바이너리, 소스 빌드로 해결.
- 무료 Apple ID로 시뮬레이터 개발은 제한 없음. 실기기 설치는 아이폰을 한 번 연결해야 프로필이 생기고, 7일마다 재설치.
- 가짜 은행 규칙: 초기 잔액 = 계좌번호 끝 4자리 × 1,000원 / 끝 `0000` 등록 실패 / 끝 `9999` 첫 조회 지연.
- cloudflared 임시 터널 주소는 껐다 켤 때마다 바뀜(→ `02_서버_다시_켜기.md`).
